= Erfahren Sie mehr über die Konfiguration von ONTAP SAN-Hosts mit NVMe-oF
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Unterstützte SAN-Hosts können für die Verwendung des NVMe over Fabrics (NVMe-oF) Protokolls mit ONTAP als Speicherziel konfiguriert werden. NVMe-oF umfasst NVMe over Fibre Channel (NVMe/FC) und NVMe over TCP (NVMe/TCP). Je nach Host-Betriebssystem (OS) und ONTAP Version wird das NVMe/FC- oder das NVMe/TCP-Protokoll oder beide auf dem Host-Betriebssystem konfiguriert und validiert.
