Die Linux Host Utilities unterstützen Sie bei der Verwaltung von ONTAP Storage, der an einen Linux Host angeschlossen ist. NetApp empfiehlt die Installation der Linux Host Utilities ausdrücklich, sie ist jedoch nicht zwingend erforderlich. Die Linux Host Utilities verbessern die Verwaltung und unterstützen den NetApp Kundensupport beim Sammeln von Informationen zu Ihrer Konfiguration.
