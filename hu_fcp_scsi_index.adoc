= Informationen zur Konfiguration von ONTAP SAN Hosts mit FCP und iSCSI
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Bestimmte SAN-Host-Betriebssysteme (OS) lassen sich für FCP und iSCSI mit ONTAP als Ziel konfigurieren. Wenn Ihr Host-Betriebssystem von der SAN Host Utilities Software unterstützt wird, wird zunächst das entsprechende Host Utility-Paket installiert, das das SAN Tool Kit enthält. Für alle Host-Betriebssystemtypen werden anschließend die Multipath-Einstellungen für ONTAP LUNs konfiguriert.

* https://docs.netapp.com/us-en/ontap/san-admin/provision-storage.html["Informationen zur Bereitstellung von SAN-Speicher"^]
